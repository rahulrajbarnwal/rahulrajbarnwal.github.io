# Rahul Raj Barnwal — Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript and deployed through GitHub Pages.

## Run locally

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Structure

- `index.html` — portfolio content and semantic structure
- `css/styles.css` — responsive layout, components and theme styling
- `js/theme-init.js` — applies the saved theme before page paint
- `js/main.js` — theme toggle and navigation interactions
- `assets/` — profile image, project marks and hero assets
- `resume.html` / `resume.pdf` — resume files

## Case studies

The portfolio includes case studies for Kotlin Multiplatform, the reusable subscription SDK, the shared networking library, Flutter offline-first development, and Domino's payment reliability work. Details are based on the supplied resume; conceptual architecture diagrams are labelled as such.
